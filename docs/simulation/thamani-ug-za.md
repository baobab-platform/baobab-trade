# Thamani Uganda–South Africa simulation pack

Gate 22 supplies a deterministic, referentially checked simulation pack for Thamani B2C. It reuses the 39-product retail catalogue and 18-supplier network from Gates 0-6, then adds fifty synthetic consumers (25 Uganda, 25 South Africa) and three order scenarios covering a domestic capture, a domestic return-and-refund, and a cross-border-import order — each with real order/payment/financial-consequence ERP expectations.

Unlike the ZuriBeans Gate 18 pack (`docs/simulation/zuribeans-ug-za.md`), whose scenarios are fabricated `SIM:...` literals never run against the database, this pack's three order scenarios are given real, persisted consequences: `npm run regression:thamani-simulation-pack` creates all 50 consumers as real Customers, then runs each scenario through Medusa's own Store-API-shaped checkout — a real Cart, a captured Payment, a real stock decrement, and (for the return scenario) a real `createAndCompleteReturnOrderWorkflow` + `refundPaymentWorkflow` — the first exercise of a return/refund workflow anywhere in this codebase. Each scenario's ERP consequences are queued through the same `DurableErpIntegrationAdapter` every other Gate uses, not a separate mechanism.

`npm run verify:thamani-simulation` validates the complete pack's referential integrity (every scenario's consumer/product/supplier reference resolves, every scenario has complete ERP expectations, at least one return/refund and one cross-border-import scenario exist) after the Thamani bootstrap chain — the same fast, no-database check `verify:simulation` does for ZuriBeans. `regression:thamani-simulation-pack` runs later, once Thamani's payments/fulfilment/tax/trade-readiness/ERP-integration modules are all bootstrapped, since it needs all of them to complete a real order.

The three completed orders are cancelled at the end of the regression run (Medusa has no order-delete primitive); the 50 consumer records are left durable, idempotently created, matching the catalogue and supplier data's own convention.
